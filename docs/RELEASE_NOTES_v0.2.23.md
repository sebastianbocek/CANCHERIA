# CANCHERIA v0.2.23

Esta versión mejora la navegación del panel de administración.

- La pestaña **Torneos** ahora mantiene visibles las inscripciones y sus acciones mediante una distribución vertical adaptable.
- Se puede modificar la proporción entre la tabla de torneos y la de inscripciones usando el separador central.
- La pestaña **Horas** responde a la rueda del mouse en toda la grilla, sin necesidad de arrastrar la barra lateral.
- `Shift` + rueda permite recorrer horizontalmente agendas con muchas canchas.

No se modificó `WPSetter.py`, el agente IA, WhatsApp ni la lógica operativa de reservas y torneos.
