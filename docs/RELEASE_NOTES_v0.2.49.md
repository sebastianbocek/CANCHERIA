# CANCHERIA v0.2.49

## Rollback operativo solicitado

Esta entrega restaura el comportamiento de `v0.2.43`, la revisión que estaba
publicada el 14 de octubre de 2026 unos minutos antes de las 15:30.

El código funcional del agente, la interfaz administrativa y las pruebas
regresan a ese punto exacto. El número de versión se incrementa a `0.2.49`
únicamente para que las instalaciones que ya recibieron `v0.2.48` puedan
actualizarse normalmente.

La actualización conserva la configuración del negocio, el perfil de
WhatsApp, calendarios, reservas y demás datos operativos existentes.

## Compatibilidad

- Windows 10/11.
- Debian/Ubuntu compatibles con el instalador Linux publicado.
- Actualización directa desde versiones anteriores mediante el actualizador de
  CANCHERIA.
