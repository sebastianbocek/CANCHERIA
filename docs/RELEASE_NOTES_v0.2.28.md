# CANCHERIA v0.2.28

Esta versión mejora el comportamiento de las notificaciones rojas del panel de administración.

- Al entrar en **ADMINISTRACIÓN** mediante el botón o su insignia roja, las notificaciones actuales quedan marcadas como leídas.
- El botón superior **Actualizar** sigue refrescando los datos reales y además marca las alertas visibles como leídas.
- Al pulsar una pestaña con una insignia roja, se marca como leída solamente esa sección.
- Los contadores de reservas, pagos, turnos y casos humanos continúan mostrando los valores operativos reales.
- La lectura queda guardada localmente, por lo que la insignia no reaparece cada tres segundos por el mismo pendiente.
- Una reserva con pago pendiente, caso humano o inscripción de torneo nueva vuelve a encender la alerta automáticamente.
