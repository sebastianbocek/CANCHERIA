# CANCHERIA v0.2.25

Esta versión mejora el aprovechamiento vertical de la pestaña **Horas**.

- Se muestran seis horarios completos simultáneamente en el tamaño habitual del panel, además de una parte del siguiente horario.
- Se compactaron márgenes, controles, leyendas, encabezados y celdas conservando el diseño moderno y redondeado.
- Permanecen disponibles los desplazamientos vertical y horizontal cuando la agenda contiene más horas o canchas.

No se modificó `WPSetter.py`, la lógica de disponibilidad, las reservas ni ninguna otra pestaña.
