# CANCHERIA v0.2.36

## Detalle histórico desde Horas

- Al activar **Mostrar todos**, las reservas pasadas pueden abrirse directamente desde su celda roja.
- Se muestra una ficha con ID, fecha, franja horaria completa, cancha, cliente, teléfono, estado y datos financieros.
- La ficha es de solo lectura: no permite modificar ni cancelar la reserva histórica.
