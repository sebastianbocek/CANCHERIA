# CANCHERIA v0.2.24

Esta versión moderniza la pestaña **Horas** del panel de administración.

- Selector de fecha y navegación con controles redondeados y mejor espaciado.
- Leyendas tipo píldora para disponibilidad, ocupación y horarios fuera de atención.
- Resumen con la fecha, la cantidad real de horarios y la cantidad real de canchas.
- Grilla visual con encabezados gris azulado, celdas redondeadas y degradado verde sutil.
- Scroll horizontal, vertical y con rueda conservados.
- Distribución adaptable validada tanto en el tamaño habitual como en el mínimo de la ventana.
- Se eliminaron las consultas automáticas de actualización al iniciar y por temporizador.
- La comprobación silenciosa ahora nace de una interacción del usuario y agrupa clics consecutivos para no agotar el límite de GitHub; **BUSCAR ACTUALIZACIONES** continúa siendo manual e inmediato.

No se modificó `WPSetter.py`, el agente IA, WhatsApp ni la lógica de disponibilidad, reservas o administración.
