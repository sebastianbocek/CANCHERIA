# CANCHERIA v0.2.17

Esta versión agrega un calendario visual al campo de fecha de `Administración → Operación`.

## Calendario para bloqueos de agenda

- La etiqueta `Fecha 📅` abre el selector de calendario.
- El calendario también se abre haciendo doble clic sobre el campo o pulsando el botón 📅.
- La fecha elegida se escribe automáticamente en formato `AAAA-MM-DD`.
- El selector utiliza el mismo componente visual de `Horas` y `Torneos`.
- Las funciones `Bloquear` y `Desbloquear` continúan trabajando con una cancha concreta o con todas las canchas.

La actualización conserva la configuración, API key, reservas, torneos, inscripciones y sesión de WhatsApp.
