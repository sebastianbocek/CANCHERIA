# CANCHERIA v0.2.64

## Corrección visual de Escuelita

El panel lateral de **Escuelita** ahora conserva la altura útil de cada sección y permite desplazarse verticalmente cuando el espacio disponible no alcanza.

Las tablas de **Grupos y cupos**, **Clases de hoy**, **Cuotas vencidas / pendientes** y **Preinscripciones por aprobar** incorporan además su propio scrollbar para navegar listas extensas sin comprimir ni ocultar filas.
