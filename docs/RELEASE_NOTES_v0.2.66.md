# CANCHERIA v0.2.66

## Promociones de tercer tiempo desde Horas

La pestaña **Horas** ahora distingue los turnos en curso en azul y los recién terminados en celeste. El estado celeste se conserva durante 60 minutos después de finalizar el bloque completo, incluso si la reserva ya pasó al historial.

Al seleccionar cualquiera de esos dos estados se abre un editor con una plantilla que usa el nombre comercial configurado. El encargado puede reemplazar `{}` por un descuento, 2x1 u otra promoción y abrir el `whatsapp_link` persistido del cliente con el mensaje listo para enviar.

La aplicación no envía el mensaje automáticamente: abre WhatsApp para que el encargado lo revise y confirme.
