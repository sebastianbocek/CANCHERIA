# CANCHERIA Windows runtime fix — 2026-10-07

## Error corregido

`ModuleNotFoundError: No module named 'cancheria.legacy_bridge'` al presionar **ENCENDER** en `cancheria.exe`.

## Causa

PyInstaller ya había cargado `cancheria.desktop` desde su archivo interno antes de que el launcher agregara `src/` a `sys.path`. Agregar `src/` a `sys.path` no modifica automáticamente el `__path__` de un paquete `cancheria` que ya existe en `sys.modules`. Por eso `WPSetter.py`, ejecutado dinámicamente con `runpy`, no podía resolver `cancheria.legacy_bridge` desde el árbol open-source externo.

## Corrección

- `configure_paths()` ahora extiende explícitamente `cancheria.__path__` con `src/cancheria`.
- Se define `CANCHERIA_INSTALL_ROOT` antes de cargar módulos de runtime.
- `cancheria.paths` respeta `CANCHERIA_INSTALL_ROOT`, evitando rutas temporales `_MEI...` de PyInstaller.
- El build incluye como hidden imports los módulos puente críticos.
- `cancheria.exe --self-test` ahora verifica `cancheria.legacy_bridge`, `cancheria.paths`, configuración, eventos y calendario antes de aceptar el release.

El objetivo es mantener los `.py` open source y editables junto a los `.exe`, sin exigir que todo WPSetter quede embebido dentro del ejecutable.
