# CANCHERIA v0.2.9

Esta versión incorpora la administración visual completa de torneos e inscripciones.

## Nueva pestaña Torneos

- Se encuentra junto a **Atención humana** dentro de Administración.
- Permite crear, editar y borrar torneos.
- Muestra fecha, valor de inscripción, premio, capacidad, confirmados, holds y lugares disponibles.
- Permite crear y editar los datos de una inscripción.
- Permite confirmar la seña, confirmar el pago total o liberar/cancelar el cupo.
- Muestra el ID administrativo, equipo, responsable, teléfono, estado, importes y método de pago.
- Las inscripciones pendientes generan una insignia roja en la pestaña y en el acceso principal a Administración.

Todas las acciones reutilizan el mismo motor transaccional y las mismas operaciones administrativas que WhatsApp.

## Comandos y configuración

La referencia resumida fue reemplazada por el catálogo completo generado por el comando `ayuda` de WhatsApp. Las categorías, descripciones y ejemplos se presentan con títulos, tipografía diferenciada y barra de desplazamiento.

## Actualización

Desde CANCHERIA v0.2.8 aparecerá automáticamente una notificación roja indicando que la versión v0.2.9 está disponible. La actualización conserva la configuración, API key, reservas, torneos, inscripciones y sesión de WhatsApp.
