# CANCHERIA v0.1.7

Primera publicación pública de CANCHERIA, el agente IA gratuito de reservas para complejos deportivos creado por AI BROTHERS.

## Incluye

- Instalador gráfico para Windows 10/11.
- Instalador de un solo archivo para Debian 12+ con escritorio.
- Configurador visual del negocio.
- Inicio de sesión de WhatsApp mediante QR y sesión persistente.
- Panel de administración para reservas, pagos y atención humana.
- Agenda visual **Horas** con disponibilidad por cancha.
- Reservas, señas, pagos, lista de espera y turnos fijos.
- Quinchos, bloqueos, reportes, torneos e inscripciones.
- Comandos administrativos desde contactos autorizados de WhatsApp.
- Respaldo ZIP automático antes de actualizar.

## Descargas

- `InstaladorCancheria.exe`: Windows 10/11.
- `InstaladorCancheriaLinux.run`: Debian 12 o posterior con escritorio gráfico.
- `DEMO-CANCHERIA-CHAT.mp4`: demostración de una interacción básica.
- `SHA256SUMS.txt`: hashes para comprobar las descargas.

## Primer inicio

1. Instalá la versión correspondiente a tu sistema.
2. Abrí **Configurar CANCHERIA**.
3. Cargá los datos del complejo y tu propia API key de OpenAI.
4. Abrí **CANCHERIA** y seleccioná **NUEVA SESIÓN**.
5. Escaneá el QR de WhatsApp.

CANCHERIA no incluye credenciales, sesiones ni datos de clientes. El software no cobra licencia; OpenAI y la infraestructura utilizada son servicios externos que pueden tener costo.
