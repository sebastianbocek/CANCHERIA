# CANCHERIA v0.2.67

## Recarga inmediata de horarios configurados

La pestaña **Horas** ahora detecta los cambios guardados desde **Configuración** y relee de forma segura el archivo operativo antes de construir la grilla.

Una franja modificada de `10:00-00:00` a `05:00-00:00` se muestra inmediatamente desde las 05:00 al volver a Administración, sin necesidad de apagar o reiniciar CANCHERIA.

La recarga sincroniza también el calendario residente para que disponibilidad, bloqueos, canchas y duraciones utilicen una única configuración.
