# CANCHERIA v0.2.18

## Nueva pestaña Blacklist

- Se agregó `Blacklist` dentro del panel de administración, inmediatamente antes de `Comandos y configuración`.
- El administrador puede ingresar un número de teléfono o nombre y bloquearlo desde la GUI.
- Los contactos bloqueados se muestran en una tabla y pueden desbloquearse seleccionándolos.
- La tabla puede actualizarse manualmente y también se refresca mientras la pestaña permanece abierta.
- La GUI usa exactamente la misma blacklist que los comandos administrativos de WhatsApp.
- Se conserva la protección que impide bloquear números administrativos autorizados.
