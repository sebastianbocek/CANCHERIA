# CANCHERIA v0.2.8

Esta versión hace que las actualizaciones sean visibles sin depender de que el operador recuerde buscarlas manualmente.

## Novedades

- El botón **AJUSTES** ahora se llama **ACTUALIZACIÓN**.
- CANCHERIA consulta automáticamente la última versión publicada al iniciar y luego cada seis horas.
- Cuando hay una versión nueva aparece una insignia roja con el número `1` sobre **ACTUALIZACIÓN**.
- La comprobación se ejecuta en segundo plano y no interrumpe el funcionamiento si GitHub o Internet no están disponibles.
- La pantalla incluye la leyenda **Software creado por Sebastián Bocek de AIBROTHERS**.
- Se agregaron accesos directos a GitHub, email y WhatsApp del creador.

## Actualización

Las instalaciones v0.2.7 pueden actualizarse desde **ACTUALIZACIÓN**. Como esta es la primera versión con aviso automático, las versiones anteriores deben buscarla manualmente una última vez desde **AJUSTES** o ejecutar el instalador completo.

Antes de reemplazar archivos, CANCHERIA crea un respaldo ZIP y conserva la configuración, la API key, los datos del negocio, las reservas y la sesión de WhatsApp.
