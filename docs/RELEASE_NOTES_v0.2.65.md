# CANCHERIA v0.2.65

## Scroll completo en Escuelita

La rueda del mouse ahora desplaza el panel lateral de **Escuelita** al ubicar el puntero sobre cualquier parte del bloque: títulos, tablas, filas o espacios vacíos.

La interacción funciona tanto con los eventos de rueda de Windows como con los de Linux, sin exigir que el cursor esté colocado directamente sobre la barra de desplazamiento.
